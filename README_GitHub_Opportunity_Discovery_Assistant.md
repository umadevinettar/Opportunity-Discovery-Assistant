# Opportunity Discovery Assistant for Women from Non-STEM Backgrounds

## Project purpose
An AI-assisted prototype to help women students and recent graduates from non-STEM backgrounds discover relevant fellowships, internships, training and professional-development opportunities.

## Knowledge base
`Opportunity_Knowledge_Base_November_2026.xlsx` is the initial curated knowledge base. It contains opportunity name, organisation, type, women relevance, target profile, discipline/area, eligibility, timing, location/mode, official link, verification date and notes.

## Important
This is a prototype knowledge base, not a guarantee of eligibility or selection. Deadlines and eligibility can change. Users must verify the official source before applying.

## Suggested assistant workflow
1. Ask for education/background, interests, skills and career goal.
2. Match the profile against the knowledge base.
3. Explain why each suggested opportunity may fit.
4. Show important eligibility/timing information.
5. Direct the user to the official source for final verification.

## Responsible AI
- Do not collect unnecessary sensitive information.
- Do not invent deadlines or eligibility.
- Distinguish database facts from AI guidance.
- Flag closed/recurring opportunities.
- Encourage official-source verification.
